# Mitra Engine

A TypeScript game engine. Mitra provides a powerful entity-component-system architecture for creating good games with ease.

## Features

- **Entity-Component-System (ECS)** architecture for flexible game object management
- **Actor-based** game objects with built-in physics, collision, graphics, and input handling
- **Scene management** for organizing game levels and states
- **Collision detection** with multiple collider types (box, circle, polygon)
- **Physics integration** via Matter.js
- **Graphics system** with sprites, shapes, and materials
- **Input handling** for keyboard, mouse, touch, and gamepad
- **Camera system** for viewport control
- **Lighting and particles** for visual effects
- **Tile map support** via Tiled plugin
- **Action system** for scripting actor behaviors
